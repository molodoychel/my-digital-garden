# Врата Балдура: Нисхождение в Авернус
![518DX_Articles_Header-Image_DIA.jpeg](/img/user/518DX_Articles_Header-Image_DIA.jpeg)
Добро пожаловать в архив кампании. Здесь будет хранилище общих материалов, заметок и идей.

## Текущая ситуация

📍 Местоположение: Врата Балдура

После исчезновения Эльтурэля отряд вернулся во Врата Балдура и поступил на службу Огненному Кулаку.

В ходе расследования были раскрыты действия культов Тиамат и Миркула, спасена драконорождённая пленница и найден загадочный бронзовый ключ от магического сундука.

После гибели Брома и Пинки к группе присоединился гоблин Робин.

Сейчас отряд выполняет поручения капитана Зоджа и собирает сведения через информатора по прозвищу Сорока. Следующая цель — продолжить расследование событий, связанных с исчезновением Эльтурэля.
## Герои приключения

```base
views:

    name: Игровые персонажи
    filters:
      and:
        - file.folder == "Персонажи/Игровые персонажи"
    order:
      - file.name

```


## Хроника кампании

```base
views:
  - type: list
    name: Игровые сессии
    filters:
      and:
        - file.folder == "Хроника сессий"
    order:
      - file.name
    sort:
      - property: file.name
        direction: ASC
    indentProperties: true
    columnSize:
      file.name: 368
      note.dg-publish: 166

```
