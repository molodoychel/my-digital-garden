# Врата Балдура: Нисхождение в Авернус
![Обложка кампании.jpeg](/img/user/%D0%9A%D0%B0%D1%80%D1%82%D0%B8%D0%BD%D0%BA%D0%B8/%D0%9E%D0%B1%D0%BB%D0%BE%D0%B6%D0%BA%D0%B0%20%D0%BA%D0%B0%D0%BC%D0%BF%D0%B0%D0%BD%D0%B8%D0%B8.jpeg)
Добро пожаловать в архив кампании. Здесь будет хранилище общих материалов, заметок и идей.

## Текущая ситуация

📍 *Текущее местоположение: [[Сведения о мире/Врата Балдура\|Врата Балдура]] -> Нижний Город -> таверна "Эльфийская песнь"*

В ходе расследования был найден лагерь Культа Дракона в лесу под Эльтурэлем и уничтожен, спасена драконорождённая пленница и найден сундук с сокровищами. В этих сокровища также был заинтересован Культ Миркула. Их группа также уничтожила : )

К сожалению, Пинки и Робин храбро пали в бою. 

Эльтурэль пал и герои отправились на пароме обратно во Врата Балдура.

Там к ним присоединился гоблин Робин. 

Сейчас отряд выполняет поручения капитана Зоджа и собирает сведения через информатора по прозвищу Сорока. Следующая цель — найти логово Культа мертвой троицы во Вратах Балдура и уничтожить.
## Герои приключения

```base
views:
  - type: cards
    name: Игровые персонажи
    filters:
      and:
        - file.folder == "Персонажи/Игровые персонажи"
    order:
      - file.name
      - status

```


## Хроника кампании

```base
views:
  - type: list
    name: Игровые сессии
    filters:
      and:
        - file.folder == "Хроника сессий"
    order:
      - file.name
    sort:
      - property: file.name
        direction: ASC
    indentProperties: true
    columnSize:
      file.name: 368
      note.dg-publish: 166

```


## Квесты

```base
views:
  - type: table
    name: Таблица
    filters:
      and:
        - file.folder == "Тайны и вопросы/Квесты"
    order:
      - status
      - file.name
    sort:
      - property: status
        direction: ASC
      - property: file.name
        direction: DESC
    columnSize:
      note.status: 108
      file.name: 739

```
