## Неигровые персонажи

```base
views:
  - type: cards
    name: Таблица
    filters:
      and:
        - file.folder == "Персонажи/NPC"
    order:
      - file.name
      - status
    sort:
      - property: status
        direction: DESC

```


## Игровые персонажи

```base
views:
  - type: cards
    name: Вид карточек
    filters:
      and:
        - file.folder == "Персонажи/Игровые персонажи"
    order:
      - file.name
      - status

```
