## Напарники

```base
views:
  - type: cards
    name: Таблица
    filters:
      and:
        - npctype == "напарник"
    order:
      - file.name
      - status
    cardSize: 120

```


## Неигровые персонажи

```base
views:
  - type: cards
    name: Карточки
    filters:
      and:
        - file.folder == "Все материалы по Авернусу/Персонажи/NPC"
    order:
      - file.name
      - status
    sort:
      - property: npctype
        direction: DESC
    cardSize: 140
  - type: table
    name: Таблица
    filters:
      and:
        - file.folder == "Персонажи/NPC"
    order:
      - status
      - file.name
    sort:
      - property: status
        direction: DESC

```


## Игровые персонажи

```base
views:
  - type: cards
    name: Герои приключения за все время
    filters:
      and:
        - file.folder == "Все материалы по Авернусу/Персонажи/Игровые персонажи"
    order:
      - file.name
      - status
    cardSize: 140
  - type: cards
    name: Погибшие герои
    filters:
      and:
        - file.folder == "Все материалы по Авернусу/Персонажи/Игровые персонажи"
        - status == "☠️"
    order:
      - file.name
      - status
    cardSize: 140
  - type: cards
    name: Живые герои
    filters:
      and:
        - file.folder == "Все материалы по Авернусу/Персонажи/Игровые персонажи"
        - status == "🟢"
    order:
      - file.name
      - status
    cardSize: 140

```
